# /lp/ ディレクトリについて

このディレクトリは、NAO WEB LAB（親テンプレートサイト）を土台に、
今後さまざまなジャンルのランディングページ（LP）を追加していくための場所です。

現時点ではサンプルLPは作成していません。このファイルは、将来LPを追加する際の
フォルダ構成のルールを示すためのものです。

## フォルダ構成の想定

```
lp/
  ├── beauty/            … ジャンル名（例：美容）
  │   └── 商品名など/
  │       ├── index.html
  │       ├── style.css
  │       ├── script.js
  │       └── images/
  │
  ├── job/                … 転職
  ├── moving/              … 引越し
  ├── app/                 … アプリ
  └── sample/              … サンプル・検証用
```

- 1つのLP = `lp/ジャンル名/商品名/` の1フォルダに、
  `index.html` / `style.css` / `script.js` / `images/` をまとめる。
- ジャンル名・商品名のフォルダ名は半角英数字（ローマ字・スラッグ形式）を推奨。
- 各LPのCSS・JSは、そのLPフォルダ内に置き、ルート直下の
  `/css/style.css` ・ `/js/main.js` は変更しない。
- ルート直下の `/css/style.css` にある共通クラス
  （`.container` `.section` `.card` `.btn` など）は、
  各LPの `style.css` から必要に応じて参照・再利用してよい。
- LP内のリンクはすべて相対パスで管理し、存在しないページへは
  リンクしない。
- 親サイト（トップページ等）へ戻るリンクを設置する場合は、
  ルートからの相対パス（例：`../../../index.html`）を使用する。

## 現在の状態

- `lp/` ディレクトリのみを用意しており、ジャンル別フォルダやLP本体は
  まだ作成していません。
- トップページの「制作可能なジャンル」「LPテンプレートについて」の
  セクションは、あくまで今後の対応予定を示すものであり、
  現時点で公開済みのLPがあることを意味しません。
