# LP作成ルール（楽天LP・A8解説ガイド共通 / 2026-11-02 制定）

オーナーの指示書（検索意図に沿い、読みやすく、広告と分かり、誇張しない）を、このサイトの全LPの共通ルールとして固定したもの。
コードでチェックできるものは `quality.py`（`check_html`）と `site_audit.py` が自動で見る。

## 1. 最初の画面
- 誰向けか／何が分かるか／画像／行動ボタンを必ず置く（楽天LP: 商品画像+「このページで分かること」+楽天ボタン）
- 冒頭に長い文章・長い広告文を置かない

## 2. PR表記
- 最初の画面の中に、読めるサイズ・色で必ず表示（A8規約・景品表示法のステマ規制）。末尾だけ・極小・薄色・折りたたみは禁止
- 一行で簡潔に。詳細は `policy.html`（広告・運営方針）へのリンクで示す。フッターにも置く

## 3. 画像
- 楽天: APIが返すURLのみ（`?_ex=` のリサイズだけ可）。加工・保存・再配布しない。画像は必ずアフィリエイトリンク付き
- A8: 許可のない画像・広告素材は使わない。図解は自作のHTML/CSS/SVG。有料の画像生成は使わない

## 4. 広告感を抑える
- ボタンは「最初」「比較・確認の後」「最後」程度。画面下固定ボタンは1つ
- ボタン文言は行き先が分かる形（「楽天市場で価格・詳細を確認する」「オリコで乗ーる公式ページで〜を見る」）。「今すぐ」「必見」等は使わない
- 注意点・向かない人・選ぶ基準を書く。紹介料率で選ばない
- 捏造禁止：口コミ、ランキング順位、在庫残数、期限、「使ってみた」などの体験談

## 5. SEO
- title / H1 / meta description をページごとに固有にする。canonical・OGP・sitemap・画像alt
- 構造化データは Google が対象にするものだけ。Product は name＋(review/aggregateRating/offers)が揃わないので付けない。FAQPage は付けない
- meta keywords は付けない。キーワードの詰め込み禁止。薄いページの量産禁止（`site_audit.py` で点検）
- 出典と確認日を載せる。価格・在庫は変動する旨を書く

## 6. 比較・選び方
- 楽天LPは「同じ種類の商品と並べて確認する」表（同カテゴリ・同種別を価格が近い順、確認日つき）。特定商品を持ち上げない
- A8ガイドは「他の買い方との違い」など中立な比較表

## 7. 速度・計測
- CSS/JSは軽量に、画像にはwidth/height、遅延読込。LCP2.5s/INP200ms/CLS0.1は目標であり、実測前に「達成」と書かない
- 新しい計測サービスは入れない（既存の分析のみ）

## 8. 確認手順
1. `python tools\rakuten-lp\run_daily.py --rerender --no-push` でテンプレ変更を全ページに反映
2. `python tools\rakuten-lp\site_audit.py` でPR・リンク・薄いページ・重複を点検
3. スマホ幅(390px)とPC幅のスクリーンショットで目視

## 9. 作る前・公開前（指示書 3・14）
- ページごとに「読者／検索意図／主キーワード／購入前の疑問／導線」を決める。同じ検索意図は統合・更新を優先
- 商品名の差し替えだけの量産は禁止。用途・比較・注意点・画像・判断材料が足りないページは公開候補にしない
- 画像が取得できないときは無関係な画像で埋めず、理由と必要素材を報告
- 完了報告は指示書15項目の7点（未確認事項・不足素材も隠さず書く）
